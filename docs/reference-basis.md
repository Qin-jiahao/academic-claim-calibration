# Reference basis / 参考依据

本项目把以下文献和官方资源作为设计依据。它们支持“谨慎表达应有证据和语境”“报告需要完整、准确、透明”等原则，不证明本 Skill 的效果，也不替代目标期刊指南。

The following literature and official resources informed the design. They support the distinction between evidence-based caution and empty hedging, and the need for complete, accurate, transparent reporting. They do not establish this Skill's effectiveness or replace a target journal's instructions.

## 学术写作中的 hedging / Hedging in scientific writing

- Hyland, K. (1998). *Hedging in Scientific Research Articles*. John Benjamins. DOI: [10.1075/pbns.54](https://doi.org/10.1075/pbns.54).
- 用途 / Use: 说明 hedging 是科学论述中的语用资源，不能把所有限定语都当成“防御性写作”删除。
- This supports treating hedging as a context-dependent pragmatic resource rather than deleting every qualifier.

## 透明和适用的报告 / Transparent, fit-for-purpose reporting

- Simera, I., & Altman, D. G. (2009). “Writing a research article that is ‘fit for purpose’: EQUATOR Network and reporting guidelines.” *Evidence-Based Medicine*, 14(5), 132–134. DOI: [10.1136/ebm.14.5.132](https://doi.org/10.1136/ebm.14.5.132). PubMed record: [PMID 19794009](https://pubmed.ncbi.nlm.nih.gov/19794009/).
- 用途 / Use: 支持按照研究类型和报告目的完整呈现方法、结果和解释边界。
- This supports reporting methods, results, and interpretive boundaries in a way that fits the study purpose and design.

## 报告指南资源 / Reporting-guideline resources

- [EQUATOR Network: How to write a great research paper using reporting guidelines](https://www.equator-network.org/toolkits/writing-research/).
- [EQUATOR Network reporting-guideline library](https://www.equator-network.org/reporting-guidelines/).
- 用途 / Use: 帮助作者根据研究设计查找适用的报告指南。此项目只提示核对，不声称已经完成 CONSORT、STROBE、PRISMA 或其他指南认证。
- These resources help authors locate guidance by study design. This project only prompts a check; it does not claim CONSORT, STROBE, PRISMA, or other compliance.
